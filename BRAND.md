# Sumnora brand system

## Core idea

Sumnora is an AI-native software development boutique. The brand is built around a single continuous path: work should move from instruction to a running system without losing context, authorship, or accountability. AI accelerates that path; an engineer still decides what ships.

## Positioning

- Category: Software development studio
- Audience: Founders, scale-ups, enterprise product teams, and operators without an engineering department
- Primary promise: Software built by a small senior team
- Brand line: Built for the work.
- Voice: Precise, calm, direct, accountable, locally grounded

## Symbol

The generated symbol uses two interlocking folds to create an abstract continuous "S." It can also be read as a secure passage moving forward. It intentionally avoids technology and AI clichés.

- Source asset: `public/brand/sumnora-logo.png` (transparent background, trimmed to the mark)
- UI adaptation: `public/brand/sumnora-mark.png` via `src/components/logo.tsx`; icons regenerated by `scripts/generate-brand-icons.ps1`
- Clear space: at least half the symbol width on every side
- Minimum digital size: 20 px high for the symbol, 92 px wide for the lockup

## Color

- Sumnora Vermillion: `#E34224` — action, decision, authorship
- Deep Ink: `#171714` — authority and legibility
- Warm Ivory: `#FBF7F2` — human, archival, calm
- Paper: `#F1ECE5` — structure and separation
- System Cobalt: `#293F7A` — restrained informational accent

Vermillion is used with discipline: decisive calls to action, key states, and brand moments. It should not wash every surface.

## Type

- Display: Newsreader Variable — editorial authority without institutional stiffness
- Interface and body: Manrope Variable — modern, highly legible, neutral
- Metadata: Manrope in uppercase with deliberate tracking
- Accessibility floor: no rendered text below 12 px; compact UI uses 13 px and supporting copy uses at least 14 px

## Anti-slop rules

- No brains, circuits, robots, sparks, chatbot bubbles, or binary digits as brand decoration.
- No blue-purple gradients, glass cards, floating blobs, or empty "AI-powered" claims.
- Lead with outcomes, constraints, and responsibilities — not feature volume or tool names.
- AI claims must name the grounding, evaluation, permission, or human approval model behind them.
- Use animation to clarify progression and state; never animate merely to make the page busy.
- Never invent proof. No client names, logos, case studies, testimonials, or metrics unless real and permitted.

## Copy conventions

- Sentence case headings, terminal period on display headings.
- American spelling (`prioritize`, `standardize`).
- One public email address: `hello@sumnora.com`.
- Use the "X, not Y" contrast sparingly — it reads as a formula past two or three uses per site.

## Imagery

The website uses two generated brand assets. Production pages use optimized WebP derivatives while full-resolution sources remain in `public/brand/`.

- `public/brand/engineering-sculpture.webp` — the hero object: delivery expressed as one continuous physical system.
- `public/brand/sumnora-team.webp` — an editorial illustration of a small engineering team.

**The team image depicts fictional people.** It carries no on-page "AI-generated" label, but it must never be captioned, described, or given alt text that presents it as a photograph of actual Sumnora personnel. The same rule applies to the capability images in `public/media/services/`.

### Hero sculpture prompt

> Use case: stylized-concept. Asset type: premium 3D hero visual for Sumnora, an AI-native software development studio. An elegant abstract sculpture representing software moving from instruction to running system: one continuous vermillion ribbon threads through a short sequence of precisely aligned translucent frosted planes, each plane subtly offset like versioned layers, held by slender brushed-stainless registration pins, terminating in one solid vermillion plane that reads as a shipped, finished state. Architectural, engineered, calm, ownable. Scene: seamless warm ivory studio environment, invisible horizon, generous negative space. Style: high-end restrained 3D product visualization, precision industrial design. Composition: wide horizontal, sculpture center-right, three-quarter perspective, strong readable silhouette. Lighting: soft museum-grade daylight, controlled soft shadows. Palette: vermillion #E34224, warm ivory #FBF7F2, translucent frosted planes, small brushed steel accents. Constraints: no text, letters, logo, people, watermark, screen interface, code editor, or terminal window. Avoid: glassmorphism UI, blue-purple gradient, glowing orb, neon, hologram, brain, robot, circuit board, binary digits, sci-fi render, generic blob, floating shapes, overly glossy plastic.

Scene: refined contemporary studio office in Metro Manila with pale stone, warm wood, subtle tropical daylight, no visible brand signage. Style: photorealistic premium editorial corporate photography, natural documentary feel, subtle film grain. Constraints: exactly three people; one man and two women; all Asian; fictional people who do not resemble celebrities or public figures; natural anatomy and hands; no readable screen text; no logos; no watermark.
